# Данные

| Файл | Что внутри |
| --- | --- |
| `catalog.json` | Все 126 шаблонов каталога Readymag: id, название, автор, рубрики, цена, число страниц. Снято 19 ноября 2026. |
| `measurements-desktop.json` | По одной записи на шаблон, снятой при окне 1024×900. |
| `measurements-phone.json` | То же при окне 375×812 с мобильным user-agent. |
| `SUMMARY.md` | Сводка и статистика по всему каталогу. |
| `table.md` | Таблица со всеми шаблонами: холст, высота, поля, колонки, число начертаний. |

## Поля записи

| Поле | Значение |
| --- | --- |
| `canvas` | Ширина холста, на котором нарисован шаблон. Вычислена как `ширина окна / zoom`. |
| `zoom` | Коэффициент масштабирования холста в окно. |
| `pageH` | Высота первой страницы в единицах холста. |
| `screens` | Сколько экранов занимает первая страница. |
| `hscroll` | Ширина содержимого, если на странице есть горизонтальная прокрутка. |
| `widgets`, `visible` | Сколько виджетов на странице всего и сколько из них видимы. |
| `kinds` | Разбивка виджетов по типам: текст, изображение, фигура, фон. |
| `marginL`, `marginR`, `contentW` | Поля и ширина содержания в единицах холста. |
| `colEdges` | Левые края заметных блоков — по ним восстанавливается колоночная структура. |
| `type` | До восьми начертаний, от крупного к мелкому. Формат: `гарнитура\|кегль\|интерлиньяж\|насыщенность`, плюс число вхождений и ширина бокса. |
| `typeCount` | Сколько всего различных начертаний на первой странице. |
| `radii` | Какие скругления встречаются и у скольких виджетов. |
| `pics`, `aspect`, `crop` | Число изображений, их пропорции и сколько из них кадрируются через `object-fit: cover`. |
| `rotated` | Сколько виджетов повёрнуто. |
| `fixed`, `pageClass` | Закреплённые виджеты и признак страницы с закреплённой шапкой. |
| `linkStates` | Цвета состояний ссылки: обычное, наведение, текущий раздел. |
| `underline` | Нарисовано ли подчёркивание фоном-градиентом вместо `text-decoration`. |
| `transitions` | Длительности переходов и сколько виджетов их используют. |

## Оговорки

- Снималась **только первая страница** каждого шаблона. У многопраничных работ внутренние
  страницы могут быть устроены иначе.
- Имена шрифтов у части шаблонов обфусцированы (`xgnl`, `tscy`, `pffk`) — Readymag
  переименовывает подключённые гарнитуры. Кегль, интерлиньяж и насыщенность при этом точные.
- Записи, где страница не успела прогрузиться, пересняты с большим ожиданием;
  в итоговых файлах остались только успешные.
- Все размеры приведены к единицам холста, см. [принцип 01](../principles/01-holst-i-masshtab.md).

## Как пересобрать

```bash
node tools/sweep.mjs data/measurements-desktop.json data/catalog.json 1024 900 6500
node tools/sweep.mjs data/measurements-phone.json   data/catalog.json 375  812 6500
python3 tools/analyze.py
```
