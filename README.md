# Репозиторий веб-вёрстки

Рабочий справочник по вёрстке для проекта «Сайт всех». Не сборник вдохновения, а набор
принципов с числами: что именно измерено, на каком материале и как это применять
в Nuxt-фронтенде прихода.

Материал первого захода — официальный каталог шаблонов Readymag: **126 шаблонов, обмеренных
в живом DOM на двух ширинах** (1024 и 375 CSS-пикселей), и отдельный разбор интерфейса самого
Readymag. Дальше справочник пополняется другими источниками.

## Что ещё внутри

- **[data/](data/)** — исходные замеры. `catalog.json` — все 126 шаблонов с рубриками и авторами,
  `measurements-desktop.json` и `measurements-phone.json` — по одной записи на шаблон:
  ширина холста, коэффициент масштаба, высота страницы, поля, края колонок, шкала кегля,
  скругления, пропорции кадров, состояния ссылок, длительности переходов.
  Сводка и статистика — в [data/SUMMARY.md](data/SUMMARY.md).
- **[templates/](templates/)** — подробные разборы отдельных шаблонов с полевыми заметками.
- **[interface/](interface/)** — разбор интерфейса Readymag: кнопки, скругления, состояния.
- **[atlas/](atlas/index.html)** — визуальный атлас: пары «десктоп / телефон», схемы, живые кнопки.
- **[tools/](tools/)** — скрипт обмера. Исследование воспроизводится одной командой.

## Как читать числа

Все размеры из шаблонов Readymag даны **в единицах холста**, если не сказано иное.
Страница Readymag — холст фиксированной ширины, который браузер масштабирует целиком
(`zoom = ширина окна / ширина холста`). Поэтому «100 px» в чужом макете — это не 100 экранных
пикселей, и переносить такое число напрямую нельзя. Подробно — в
[принципе 01](principles/01-holst-i-masshtab.md).

Пометки в тексте:

- **измерено** — значение получено из `getComputedStyle` или `getBoundingClientRect` в живой странице;
- **на глаз** — снято со скриншота, точность до нескольких пикселей.

## Как повторить замеры

```bash
node tools/sweep.mjs data/measurements-desktop.json data/catalog.json 1024 900 6500
node tools/sweep.mjs data/measurements-phone.json   data/catalog.json 375  812 6500
```

Нужен Node 22+ и установленный Chrome. Скрипт поднимает headless-Chrome, открывает каждый
шаблон по адресу `readymag.com/<id>` и снимает замеры через протокол отладчика.
Файл дописывается по мере работы, повторный запуск продолжает с места остановки.

Живой просмотр любого шаблона — `https://readymag.com/<id>`, это тот же адрес, что
за кнопкой Preview в каталоге. Список всех шаблонов — `https://readymag.com/api/templatesets`.
