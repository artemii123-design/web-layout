# 05 · Состояния и наведение

> **По всему каталогу.** Состояние наведения описано у **53 %** шаблонов, состояние
> «текущий раздел» — у **52 %**: примерно половина авторов вообще не отмечает, где человек
> находится. Подчёркивание нарисовано фоном-градиентом вместо `text-decoration` у **40 %**.
> Длительность перехода почти всегда одна: **0,2 с** — 1338 виджетов из 1375,
> на 0,1 с приходится 25, на 0,5 с — 10.

## Грамматика, одинаковая во всех шаблонах

Выписано из реальных правил CSS на живых страницах:

```css
/* карточка превью в каталоге */
.card { aspect-ratio: 1.52/1; border-radius: 4px; overflow: hidden; }
.card:hover { opacity: .7; }

/* ссылка, базовый стиль Readymag */
.link-1 { text-decoration: none; padding-bottom: 1px; background: none; }
.link-1:hover { color: #0080FF; }

/* изображение */
.widget-picture { transition: opacity .2s; }
```

**Ни в одном из семи разобранных шаблонов при наведении не меняются `transform`,
размер или положение.** Обратная связь — только цвет и прозрачность, 0,1–0,2 с.

Это совпадает с нашим правилом: hover не двигает элементы по вертикали и не масштабирует
изображения; обратную связь даём цветом, фоном, обводкой, подчёркиванием или тенью
без изменения геометрии.

## Четыре состояния вместо двух

Planet Earth хранит стиль ссылки как класс `link-style-<uuid>` с полным набором состояний:

| Состояние | Значение | Смысл |
| --- | --- | --- |
| обычное | `color: #333; padding-bottom: 1px` | без подчёркивания |
| наведение | `rgba(51,51,51,.6)` | **тот же цвет гаснет до 60 %** |
| текущий раздел | `#FF4D00` | единственное место акцента |
| недоступно | `rgba(51,51,51,.25)` + подпись «comming soon» | видно, но не кликается |

Второй стиль в том же проекте: подчёркивание сделано **фоном-градиентом**
`background: linear-gradient(...) 0 100% / 1px 1px repeat-x`, а не `text-decoration` —
так линия ставится ровно в 1 px под базовой линией; на наведении она убирается,
а цвет гаснет до альфы 0,8.

**Что берём.** Наведение как гашение того же цвета, а не подстановка другого, —
спокойнее и не требует второй палитры. Текущий раздел — единственное место акцента.
Недоступный пункт показываем, а не прячем.

У нас для акцентного текста есть `--color-accent-ink`, а `--accent-fill` — поверхность.
Текущий пункт навигации — это `--color-accent-ink`, а не заливка.

## Что показывать по наведению

| Приём | Где измерено | Чему служит |
| --- | --- | --- |
| Гашение до 70 % | карточка каталога Readymag | «это кликается», без смены макета |
| Подмена подложки | Unveil, `transition-duration: 0s` | смена образа, рамка неподвижна |
| Заливка цветом категории | фильтры каталога | кодирует рубрику цветом |
| Появление подсказки прокрутки | Calendar, галочка внизу | появляется после движения мыши, не висит постоянно |

Последнее стоит перенять: **подсказки прокрутки показывать по движению, а не постоянно.**

## Фокус

У фильтров каталога Readymag стоит `:focus { outline: none }` — клавиатурная навигация
теряет фокус полностью. Это ошибка, и повторять её нельзя.

Наше правило остаётся: hover-стили пишем только внутри `@media (hover: hover)`,
focus/active/aria-состояния остаются доступными без hover.

## Проверочный список

- [ ] Ни одно состояние не меняет `transform`, ширину, высоту или положение.
- [ ] Длительность перехода 0,1–0,2 с, свойство названо явно (не `all`).
- [ ] У ссылки описаны четыре состояния, а не два.
- [ ] Текущий раздел отмечен акцентным **текстом**, а не заливкой.
- [ ] Недоступный пункт виден и объяснён.
- [ ] `:focus-visible` даёт видимый контур.
- [ ] Hover-правила внутри `@media (hover: hover)`.
