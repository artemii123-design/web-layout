Замеры сняты с `readymag.com/templates` и `readymag.com/templates/details/<id>` при 1440×900,
значения получены из `getComputedStyle` и реальных правил CSS в документе.

Замеры с `readymag.com/templates` и `readymag.com/templates/details/<id>` при 1440×900.

## Скругления: три разных языка на одном сайте

| слой | радиус | что им оформлено | размер элемента |
|---|---|---|---|
| маркетинговая шапка и CTA | **200px** | Solutions, Pricing, Examples, Templates, Learn, Log in, Sign up | все 40 px высотой |
| фильтры каталога | **40px** | Company website / Landing page / Presentation / Portfolio / Editorial / All sources / Free+Paid | тоже 40 px высотой |
| превью шаблона в каталоге | **4px** | карточка 309×203 (×126 на странице) | 309×203 |
| тег категории | **4px** | «Presentation» | 88×24 |
| продуктовый слой (страница шаблона) | **8px** | большая карточка 1333×629, кнопки 152×40 и 153×40, «Contact support» 126×32, превью страниц 439×289 и 158×280 | от 126 до 1333 px |

Три вывода, которые видно только в цифрах:
1. **200px и 40px при высоте 40 дают одну и ту же форму** — полную пилюлю. Это два разных способа
   сказать одно и то же: единого токена у Readymag нет, есть исторические слои.
2. **Радиус не зависит от размера элемента.** 8 px стоит и на кнопке 126×32, и на карточке 1333×629.
   Радиус кодирует *слой интерфейса*, а не величину объекта.
3. На странице шаблона **радиус 8 равен зазору между превью 8**. Карточки 439×289 (3 в ряд) и
   158×280 (8 в ряд) стоят с шагом 447 и 166 — зазор в обоих случаях ровно 8.

## Кнопки: высота, кегль, внутренние отступы

| кнопка | размер | радиус | кегль / интерлиньяж | боковой паддинг | заливка | обводка |
|---|---|---|---|---|---|---|
| Sign up | 102×40 | 200px | 16 | 24 | `#EC520B` | нет |
| Log in | 91×40 | 200px | 16 | 24 | `#F4F4F4` 96 % | нет |
| пункт меню (Pricing…) | 88–122×40 | 200px | 16 | 24 | `#F4F4F4` 96 % | нет |
| фильтр каталога | 106–177×40 | 40px | 16 / 20, ls −0,04 | 23 | прозрачная | **1px белая** |
| Open in Editor | 152×40 | 8px | 16 | — | `#0080FF` | нет |
| Preview | 153×40 | 8px | 16 / 20 | — | прозрачная | **1px `rgba(162,162,162,.196)`** |
| Contact support | 126×32 | 8px | 12 / 16 | — | `#4E4E4E` | нет |
| «Copy template» в просмотре | 160×56 | 28px (= половина высоты) | — | — | `#808080` | нет |

Соотношения:
- **высота кнопки = 2,5 кегля** (40 / 16) — для всей основной линейки;
- **боковой паддинг = 1,44–1,5 кегля** (23–24 / 16);
- свободное поле над и под текстом — (40 − 20) / 2 = **10 px**;
- мелкая кнопка держит ту же логику: 32 / 12 = 2,67 кегля;
- плавающая кнопка в просмотре выпадает из системы: 56 px высотой и радиус ровно h/2.

## Состояния — выписаны из реальных правил CSS

- **Карточка шаблона**: `aspect-ratio: 1.52/1; border-radius: 4px; overflow: hidden;`
  `:hover { opacity: .7 }`. **Никакого подъёма, тени, увеличения кадра.**
- **Пункт меню**: `:hover { color: white; background-color: #8C8C8C }`.
- **Фильтры: у каждого свой цвет наведения** — это целая система:
  | фильтр | цвет при наведении |
  |---|---|
  | Company website | `#8C8C8C` серый |
  | Landing page | `#FFCB00` жёлтый |
  | Presentation | `#408D27` зелёный |
  | Portfolio | `#FF7CBE` розовый |
  | Editorial | `#0080FF` синий |
  | All sources | `#FF0000` красный |
  Переход `transition: color .1s` — только цвет, 100 мс.
- **Открытый фильтр**: пилюля заливается своим цветом, а **всё за ней уходит в `backdrop-filter:
  blur(10px)`**. Самого меню как панели нет: ни фона, ни тени, ни скругления — просто список
  текстом, кегль **26/26**, текущий пункт оранжевый `#EC520B`, остальные тёмные `#282828`.
- **`:focus { outline: none }`** у фильтров — клавиатурная навигация теряет фокус. Это ошибка,
  повторять её не нужно.
- **Плавающая кнопка просмотра**: `transition: background-color .2s ease-in-out`,
  `#808080` → `#313131` при наведении; у обёртки `transition: transform .3s`.

## Карточка каталога и сетка

- Сетка: **4 колонки по 309, межколонник 32**, контейнер 1332 по центру 1440 → поля 54.
- Карточка: превью **309×203 (1,52:1)** + подпись. Шаг ряда 284 → между рядами 32 + подпись 41.
- Превью страницы шаблона: **439×289 (1,52:1)** на десктопе и **158×280 (0,56:1)** на телефоне —
  переключатель из двух иконок 23×23 с шагом 35 в правом верхнем углу блока «Pages».
  То есть Readymag показывает ровно **два формата кадра** и ничего между ними.
- Главная карточка страницы шаблона: **1333×629, разрезана на 373 + 959 (28 % / 72 %)**,
  радиус 8 нарисован только по внешним углам (`8px 0 0 8px` и `0 8px 8px 0`).
